The project

Civ II, carefully reconstructed.

This independent, non-commercial project recreates Civilization II Multiplayer Gold Edition with modern browser technology while keeping the original game’s graphics, proportions, interactions, and mechanics.

The engine uses JavaScript, Canvas 2D, Vite, and optional 2× sprite upscaling. The project is backed by a full browser regression suite and cross-checked against the running MGE game and published technical references.
